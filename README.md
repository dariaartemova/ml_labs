# Машинное обучение: лабораторные работы

Практические работы по анализу данных и машинному обучению на Python.

**Стек:** Python, pandas, numpy, scikit-learn, statsmodels, matplotlib, seaborn, Streamlit

| № | Тема | Методы |
|---|------|--------|
| 1 | Разведочный анализ данных | статистики, визуализация, корреляции |
| 2 | Предобработка данных | пропуски, кодирование категорий, масштабирование |
| 3 | Подготовка выборок | train/test split, кросс-валидация, подбор гиперпараметров (KNN) |
| 4 | Классификация | логистическая регрессия, SVM, деревья решений |
| 5 | Ансамбли моделей, ч. 1 | Bagging, AdaBoost, Gradient Boosting |
| 6 | Ансамбли моделей, ч. 2 | стекинг, Random Forest, нейросеть (MLP) |
| 7 | Временные ряды | декомпозиция, тест Дики-Фуллера, ARIMA, символьная регрессия |
| 8 | Веб-приложение с ML-моделью | Streamlit, Random Forest, ROC-кривые, матрица ошибок |
| 9 | Обучение без учителя | KMeans, PCA, t-SNE, метрики кластеризации |

В каждой папке: Jupyter-ноутбук (или код приложения) с выводами и отчет.

Запуск веб-приложения из лабы 8:
pip install streamlit scikit-learn pandas matplotlib seaborn
streamlit run Lab8/app.py
